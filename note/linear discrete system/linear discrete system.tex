\chapter{线性离散系统}

\section{A/D转换}

\subsection{A/D转换}

A/D转换器将模拟信号变成数字信号。A/D转换的过程可以看作是采样、量化和编码过程

采样的过程如下图所示，假设采样开关每隔一定时间$T$闭合一次，则称$T$为采样周期，则采样频率为
\begin{center}
    \includegraphics[width = .6\textwidth]{note/linear discrete system/figure/1.png}
\end{center}

\begin{equation*}
    f_s = \frac{1}{T}
\end{equation*}

而采样角频率为
\begin{equation*}
    \omega_s = \frac{2\pi}{T} = 2\pi f_s
\end{equation*}

采样过程可以看作是一个脉冲调制过程。设理想的单位脉冲序列为：
\begin{equation*}
    \delta_T (t) = \sum_{k=0}^\infty \delta(t-kT)
\end{equation*}

由此可以得到模拟信号的采样信号为：
\begin{equation*}
    e^* (t) = e(t) \delta_T(t) = \sum_{k=0}^\infty e(KT) \delta(t-KT)
\end{equation*}

量化就是采用有限字长的一组二进制数去逼近离散模拟信号的幅值。在计算机中，任何数值都可以表示成二进制数字量最低位的整数倍。数字量最低为所代表的数值称为量化单位通常用$q$来表示

编码就是将量化后的数值变成按某种规则编码的二进制数码。常用的编码形式有：原码，补码，偏移码、BCD码等。

\subsection{离散信号的频谱}

对于一个频谱有限连续时间信号$x(t)$，其Fourier变换为：
\begin{equation*}
    X(j\omega) = \int^\infty_{-\infty} x(t)e^{-j\omega t} dt
\end{equation*}

同样的，对于一个理想采样信号$x^* (t) = x(t) \delta_T(t) = \sum\limits_{k=0}^\infty x(KT) \delta(t-KT)$，我们可以写出他的Fourier变换：
\begin{equation*}
    X_s(\omega) = \frac{1}{2\pi} X(\omega)*(\omega_s \sum\limits_{n=-\infty}^{+\infty} \delta(\omega-n\omega_s)) = \frac{1}{T_s}\sum\limits_{n=-\infty}^{+\infty}X(\omega-n\omega_s)
\end{equation*}

考虑需要不失真地恢复原来的连续信号，理想采样角频率需要满足以下定理：

\begin{theorem}[Shannon定理]
    对于频谱有限信号$x(t)$，如果其最高频率分量为$\omega_m$，为了保留原信号的全部信息，或能无失真地恢复原信号，在通过采样得到离散信号时，其采样频率应满足$\omega_s\geq 2\omega_m$。通常把最低允许的采样频率$\omega_s = 2\omega_m$称为Nyquist频率，最大允许采样间隔$T_s = \dfrac{\pi}{\omega_m}$称为Nyquist间隔
\end{theorem}

在工程实际中，采样角频率往往取的比Nyquist频率要大得多

\subsection{采样周期的选取}

在Shannon定理中，采样周期需要越小越好，但是在工程实际中，采样周期取得过短，将会增加不必要的计算负担。反之，采样周期取得过长，又会给控制过程带来较大的误差，降低系统的动态性能

所以，根据工程实践的经验，伺服系统的采样频率可选为：
\begin{equation*}
    \omega_s \approx 10\omega_c
\end{equation*}

其中$\omega_c$为开环系统的幅值穿越频率


\section{D/A转换}
D/A转换器将数字信号转换为模拟信号。D/A转换的过程可以看成是解码和保持的过程

解码就是根据D/A转换器所采用的编码规则，将数字信号折算成对应的电压或电流值。这个电压或电流值仅仅是对应各采样时刻的，而相邻两采样时刻之间的值还没有确定。

保持就是解决各相邻采样时刻之间的插值问题，将离散时间信号变成连续时间信号。实现保持功能的器件称为保持器。保持器有各种类型，D/A转换器中一般使用零阶保持其，其传递函数通常记为$H_0(s)$。零阶保持器是一种具有常值外推功能的保持器，它将采样时刻的电压或电流值不增不减地保持到下一个采样时刻到来之前。

\section{Z变换与Z反变换}

\subsection{Z变换}

考虑一个对连续信号进行理想采样的离散信号：
\begin{equation*}
    x^* (t) = x(t) \delta_T(t) = \sum\limits_{k=0}^\infty x(KT) \delta(t-KT)
\end{equation*}

其Laplace变换为：
\begin{equation*}
    X^*(s) = \sum_{k=0}^\infty x(kT)e^{-kTs}
\end{equation*}

记复变量$z = e^{-Ts}$，则上式可以写为：
\begin{equation*}
    X(z) = \sum_{k=0}^\infty x(kT)z^{-k}
\end{equation*}

\begin{definition}
    称式子
    \begin{equation*}
    X(z) = \sum_{k=0}^\infty x(k)z^{-k}
    \end{equation*}
    为离散信号$x(k)$的Z变换，记为：$X(z) = Z[x(t)]$

    \textbf{注}：
    \begin{enumerate}
        \item     在本笔记中，记连续信号$x(t)$理想采样各个值$x(kT)$为$x(k)$，与信号分析与处理类似
        \item 默认连续信号存在Z变换，且其Z变换与其理想采样信号的Z变换相同
    \end{enumerate}


    
\end{definition}

\subsection{求Z变换的常用方法}

\subsubsection{级数求和法}

由Z变换的定义可以得到：
\begin{equation*}
    X(z) = x(0) + x(1) z^{-1} + x(2) z^{-2} + \cdots + x(k) z^{-k} +\cdots
\end{equation*}

这是$X(z)$的laurent级数表达式，故只要知道$x(k)$的闭式表达，即可求出其Z变换

\subsubsection{部分分式法}
利用部分分式法求Z变换时，先求出连续函数$x(t)$的Laplace变换$X(s)$。$X(s)$通常是$s$的有理分式，将其展成部分分式之和的形式，使每一部分分式对应简单的时间函数。然后分别求出每一项的Z变换。最后作同分简化运算，求得$x(t)$采样序列所对应的Z变换$X(z)$。

\subsubsection{留数计算法}
若已知连续信号$x(t)$的Laplace变换$X(s)$和它的全部极点$s_i$，可用以下公式求出其Z变换：
\begin{equation*}
    X(z) = \sum_{i=1}^n \text{Res} [X(s)\frac{z}{z-e^{sT}},s_i]
\end{equation*}

\subsection{Z变换的性质与定理}
在介绍Z变换的性质与定理之前，先假设有n个连续函数$x_i(t)\,(i\leq n)$，他们的Z变换分别为：$X_i(z)\,(i\leq n)$

\subsubsection{线性性质}

Z变换的线性性体现在如下式子：
\begin{equation*}
    Z[\alpha x_1(t) +\beta x_2(t)] = \alpha X_1(z) + \beta X_2(z)
\end{equation*}

其中$\alpha , \beta $为常数

\subsubsection{实数位移定理}

实数位移定理包括滞后定理与超前定理，以下分别介绍：
\begin{enumerate}
    \item （滞后定理）：$Z[x_1 (t-nT)] = z^{-n} X_1 (z)$
    \item （超前定理）：$Z[x(t+nT)] = z^n [X(z) - \sum\limits_{k=0}^{n-1} x(k) z^{-k}]$
\end{enumerate}

\subsubsection{初值定理}
如果信号$x_1(t)$满足因果性，则其满足以下式子：
\begin{equation*}
    x_1(0) = \lim\limits_{z\rightarrow \infty} X_1(z)
\end{equation*}

\subsubsection{终值定理}
如果$X_1(z)$满足$(z-1)X_1(z)$的全部极点都位于$z$平面单位圆内，则：$x_1(t)$在$\infty$处存在极限，且有
\begin{equation*}
    x_1(\infty) = \lim\limits_{z\rightarrow 1}(z-1)X_1(z)
\end{equation*}

\subsubsection{卷积定理}

卷积定理满足以下式子：
\begin{equation*}
    Z[x_1(t) * x_2(t)] = X_1(t) X_2(t)
\end{equation*}

\subsection{Z反变换}

\begin{definition}
    称根据$X(z)$反求$x(k)$的过程称为Z反变换，记为$Z^{-1}[X(z)]$，即$Z^{-1}[X(z)] = x(k)$
\end{definition}

以下介绍Z反变换的几种计算方法：

\begin{enumerate}
    \item 长除法：当$X_(z)$为$z$的有理分式时，可以用长除法求出其留数表达式，然后求出其Z反变换（不常用，略）
    \item 部分分式法：可以将$X(z)$写为若干个分式之和，其中每个分式对应Z变换中的一项，便可求出其Z反变换。具体式子如下：（举其中一种例子，这种方法的使用也不多）
    \begin{equation*}
        X(z) = \sum_{i=1}^n \frac{A_i z}{z-z_i}
    \end{equation*}

    其中$z_1,\cdots,z_n$为$X(z)$的极点
    \item 留数计算法：假设$X(z)$的极点分别为$z_1,\cdots,z_n$，则其反变换$x(k)$可写为以下形式：
    \begin{equation*}
        x(k) = \sum_{i=1}^n \text{Res}[X(z)z^{k-1},z_i]
    \end{equation*}

    注意：$k=0$的情况有可能需要单独讨论，此处$z=0$可能为新的极点
\end{enumerate}

\section{脉冲传递函数}

\subsection{脉冲传递函数的概念}
\begin{definition}
    脉冲传递函数，也成称为Z传递函数，是线性离散系统或环节的一种数学模型，可以反应线性离散系统的特性。

    脉冲传递函数的物理意义为：已知一个连续系统的传递函数为：$G(s)$，则通过对$G(s)$的单位脉冲相应$g(t)$的采样序列$g^* (t)$求Z变换，可得该环节的脉冲传递函数。

    脉冲传递函数的性质如下：
    \begin{enumerate}
        \item $G(z)$是关于$z$的复函数
        \item $G(z)$与输入输出序列无关，仅与系统的结构参数有关
        \item $G(z)$与系统差分方程一一对应
        \item $G(z)$相当于系统单位脉冲响应序列的Z变换
        \item $G(z)$对应$z$平面的零极点图
    \end{enumerate}

    脉冲传递函数还具有一定的局限性：原则上其不反应非零初始条件下系统响应的全部信息、一边只适合SISO离散系统、只适用于描述线性定常离散系统等。
\end{definition}

\subsection{串联环节的脉冲传递函数}
\subsubsection{串联环节间无同步开关}

如图所示串联环节间无同步采样开关时，其脉冲传递函数为$G(z) = Y(z)/E(z)$，可由描述连续工作状态的传递函数$G_1(s)$和$G_2(s)$的乘积$G_1(s)G_2(s)$求取，记为:
\begin{center}
    \includegraphics[width = .4\textwidth]{note/linear discrete system/figure/5.png}
\end{center}
\begin{equation*}
    G(z) = Z[G_1(s)G_2(s)] = G_1G_2(z)
\end{equation*}

上述结论可以推广到无采样开关隔离的$n$个环节相串联的情况中，即：
\begin{equation*}
    G(z) = Z[G_1(s)\cdots G_n(z)] = G_1\cdots G_n(z) 
\end{equation*}

\subsubsection{串联环节间有同步开关}
如图所示两串联环节间用同步采样开关隔离时，有：
\begin{center}
    \includegraphics[width = .4\textwidth]{note/linear discrete system/figure/6.png}
\end{center}
\begin{equation*}
    \begin{split}
        M(z) &= G_1(z)E(z) \quad G_1(z) = Z[G_1(s)] \\
        Y(z) &= G_2(z)M(z) \quad G_2(z) = Z[G_2(s)] \\
    \end{split}
\end{equation*}

于是，脉冲传递函数为：
\begin{equation*}
    G(z) = \frac{Y(z)}{E(z)} = G_1(z) G_2(z)
\end{equation*}

同样的，可以将上述情况推广到有同步采样开关隔开的$n$个环节相串联的情况，即：
\begin{equation*}
    G(z) = Z[G_1(s)]\cdots Z[G_n(s)] = G_1(z)\cdots G_n(z)
\end{equation*}

\subsubsection{零阶保持器与串联环节串联}

如图所示为零阶保持器与环节串联的情况，可以得到其传递函数为：
\begin{center}
    \includegraphics[width = .4\textwidth]{note/linear discrete system/figure/7.png}
\end{center}
\begin{equation*}
    G(z) = (1-z^{-1}) Z\left[ \frac{G_0(s)}{s} \right]
\end{equation*}

\section{差分方程}

\subsection{线性常系数差分方程}

$n$阶后向非齐次差分方程的基本形式如下：
\begin{equation*}
    y(k)+ \sum_{i=1}^n a_i y(k-i) = \sum_{j=0}^m b_j r(k-j)
\end{equation*}

$n$阶前向非齐次差分方程的基本形式如下：
\begin{equation*}
    y(k+n) + \sum_{i=1}^n a_i y(k+n-i) = \sum_{j=1}^m r(k+m-j)
\end{equation*}

\subsection{差分方程的求解}

差分方程常用迭代法和Z变换法来求解，下面进行一一介绍

\subsubsection{迭代法}
迭代法是一种递推的方法，适合计算机进行递推运算求解。$n$阶后向差分方程的一般形式为：
\begin{equation*}
    y(n) = -\sum_{i=1}^n a_i y(k-i) + \sum_{j=0}^m b_j r(k-j)
\end{equation*}

只要知道了初始条件，即输出序列的初始值$y(0),\cdots , y(n-1)$ 和任意时刻的输入序列$r(k)\,k=0,\cdots$，那么系统任何时刻输出序列的值$y(n)$都可以逐步递推出来

\subsubsection{Z变换法}
用Z变换法求解差分方程的实质是利用Z变换的位移定理，将差分方程化为以$z$为变量的代数方程，然后进行Z反变换，求出各采样时刻的响应。用Z变换法解差分方程的步骤为：
\begin{enumerate}
    \item 对差分方程进行Z变换
    \item 解出方程中输出量的Z变换$Y(z)$
    \item 求出$Y(z)$的Z反变换，得到差分方程的解$y(k)$
\end{enumerate}

\subsection{由差分方程求系统脉冲传递函数}
与连续函数非分方程求传递函数类似，步骤如下：
\begin{enumerate}
    \item 保证系统是处于零状态响应
    \item 将差分方程两侧作Z变换
    \item 求出$\frac{Y(z)}{R(z)}$
\end{enumerate}

\section{线性离散系统的时域分析}

\subsection{极点在$z$平面上的分布与瞬态响应}

设一个线性离散系统的闭环脉冲传递函数为：
\begin{equation*}
    \Phi (z) = \frac{M(z)}{D(z)} = \frac{k\prod\limits_{j=1}^m (z-z_j)}{\prod\limits_{i=1}^n (z-p_i)}
\end{equation*}

其中，$M(z)$为$\Phi(z)$的分子，$D(z)$为$\Phi(z)$的分母，$z_j$为系统的闭环零点，$p_i$为系统的闭环极点

当$r(t) = 1(t)$，$R(z) = \frac{z}{z-1}$时，系统的输出的Z变换为：
\begin{equation*}
    Y(z) = \frac{k\prod\limits_{j=1}^m (z-z_j)}{\prod\limits_{i=1}^n (z-p_i)} \frac{z}{z-1}
\end{equation*}

当特征方程无重根时，$Y(z)$可展开为：
\begin{equation*}
     Y(z) = \frac{Az}{z-1} + \sum_{i=1}^n \frac{B_i z}{z - p_i}
\end{equation*}

其中$A = \left. \frac{M(z)}{D(z)} \right|_{z=1} $，$B_i = \left. \frac{M(z)(z-p_i)}{D(z)(z-1)} \right|_ {z=p_i}$。对上式进行Z反变换可以得到：
\begin{equation*}
    y(kT) = A + \sum_{i=1}^n B_i p_i ^ k
\end{equation*}

系统的瞬态响应分量为：
\begin{equation*}
    \sum_{i=1}^n B_i p_i^k
\end{equation*}

显然极点在z平面上的位置决定了瞬态响应中各分量的类型

\subsubsection{实数极点}
当闭环脉冲函数的极点位于实轴上，则在瞬态响应中将含有一个响应的分量：
\begin{equation*}
    y_i (kT) = B_i p_i^k
\end{equation*}

\begin{enumerate}
    \item 若$0< p_i <1$，极点在单位圆内正实轴上，其对应的瞬态响应序列单调递减
    \item 若$p_i = 1$，响应的瞬态响应是不变号的等幅序列
    \item 若$p_i >1$，极点在单位元外正实轴上，对应的瞬态响应序列单调发散
    \item 若$-1 < p_i <0$，极点在单位圆内负实轴上，对应的瞬态响应是正负交替变号的衰减振荡序列，振荡角频率为$\frac{\pi}{T}$
    \item 若$p_i = -1$，对应的瞬态响应是正负交替变号的等幅序列，振荡角频率为$\frac{\pi}{T}$
    \item 若$p_i < -1$，极点在单位圆外负实轴上，相应的瞬态响应序列是正负交替变号的发散序列，振荡角频率为$\frac{\pi}{T}$
\end{enumerate}

\subsubsection{共轭复数极点}

如果闭环脉冲传递函数有共轭副书记点$p_{i,i+1} = a \pm jb$，可以证明，这对共轭复数极点所对应的瞬态相应分量为：
\begin{equation*}
    y_i(kT) = A_i \lambda_i ^k \cos(k \theta_i + \varphi_i)
\end{equation*}

其中$\lambda_i = \sqrt{a^2 + b^2} = \left\lvert p_i \right\rvert $ ， $\theta_i = \arctan \dfrac{b}{a}$，$A_i,\varphi_i$由部分分式展开式的系数所决定的常数

\begin{enumerate}
    \item 若$\lambda_i =\left\lvert p_i \right\rvert <1 $ ，极点在单位圆之内，这对共轭复数极点所对应的瞬态响应是收敛振荡的脉冲序列，振荡角频率为$\frac{\theta_i}{T}$
    \item 若$\lambda_i =\left\lvert p_i \right\rvert = 1$，这对共轭复数极点在单位圆上，其瞬态响应是等幅振荡的脉冲序列，振荡角频率为$\frac{\theta_i}{T}$
    \item 若$\lambda_i =\left\lvert p_i \right\rvert >1$，极点在单位圆外，这对共轭复数极点所对应的瞬态响应是振荡发散的脉冲序列，振荡角频率为$\frac{\theta_i}{T}$
\end{enumerate}

上述振荡过程，其振荡角频率都由相角$\theta_i$决定。$\theta_i$是极点$p_i$与正实轴的夹角，可以得到：

振荡角频率为：
\begin{equation*}
    \omega_i = \frac{\theta_i}{T}
\end{equation*}

一个振荡周期中所含采样周期的个数$N$可由以下式子求出：
\begin{equation*}
    N = \frac{\omega_s}{\omega_i} = \frac{2\pi}{\theta_i}
\end{equation*}

\subsection{线性离散系统的时间响应}
如同连续系统，离散系统的过渡过程也常用典型信号作用下系统的响应来衡量。如利用单位阶跃响应、单位斜坡响应等来分析系统的过渡过程。但离散系统中所研究的是过渡过程中各采样时刻上的离散信号

当已知闭环，闭环脉冲传递函数及典型输入信号的Z变换时，可救出输出信号的Z变换$Y(z)$，然后用Z反变换求出时域响应$y^*(t)$。虽然有些系统无法写出闭环脉冲传递函数，但是$Y(z)$的表达式总是能写出的，因此求取$y^*(t)$并没有什么困难
